# MixLab

Offline AI-DJ research: discover musically strong track combinations, render real transitions, and prove quality with blind listening.

Canonical project: https://app.notion.com/p/3e79e19ac95581a78ee3f24aa5e7e8b6

Current phase: M0 foundation and M1 Transition Lab implementation. No musical-quality gate has passed yet.

The initial implementation is being prepared with deterministic audio rendering, private source provenance, synthetic smoke fixtures, and independently reviewed worker handoff. Real music, stems, rendered private mixes and credentials must never enter this public repository.
